# 🚗 YOLO11 + SAM 2.1 | Vehicle Video Segmentation

Build an AI-powered vehicle segmentation system using **YOLO11 and SAM 2.1**!

Detect and segment cars, motorcycles, buses, and trucks in videos with pixel-level masks.

## ✨ Features
- 🚗 Detect multiple vehicle categories using YOLO11.
- 🎯 Generate segmentation masks using SAM 2.1.
- 🎨 Apply colored masks and bounding boxes.
- 🎥 Process complete videos and save the output.

## 🛠️ Technologies
Python | YOLO11 | SAM 2.1 | OpenCV | NumPy | Google Colab
